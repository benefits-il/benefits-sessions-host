# benefits-sessions-host — קונסולת ההוראה של הקורס

אתר HTML סטטי **מנחה-בלבד**, תאום של אתר-התלמיד [benefits-sessions](https://benefits-il.dev/benefits-sessions/). זו לא העתקה של תוכן-התלמיד — זו **קונסולת-הוראה**: קוקפיט של מצגות, לינקים והערות-מעבר, מסודר פר-מפגש ובסדר-ההוראה, שדרכו בן זורם בשיעור — פותח את המצגת הנכונה ושולף-ושולח לתלמידים את מה שצריך. אתר ביניים עד שהפלטפורמה (benefits-il) מוכנה.

**גישה:** פרטית לבן, רכה (ביניים). הפלטפורמה תטפל באבטחה אמיתית בהמשך.

## איך זה בנוי

שלוש שכבות:

1. **קליפת ניווט** — עמודי HTML סטטיים: שער (`index.html`), אינדקס שיעורים (`sessions.html`), ועמוד-קונסולה פר-מפגש (`session-<N>.html`).
2. **מצגות** — הדקים של היחידות מתארחים כאן תחת `decks/session-<N>/<unit>/slides.html` (כל דק עם תיקיית `assets/` שלו). הערות-הדובר חיות בתוך הדק עצמו — נפתחות עם כפתור-ההצגה של הדק.
3. **עיצוב** — `delivery.css` מועתק זהה-בייט מאתר-התלמיד (אותם טוקנים, אותה שפת-רכיבים), plus `console.css` שמוסיף את הרכיבים המנחה-בלבד (כרטיס-צעד, סלוט-מצגת, רשימת-לינקים, הערת-מעבר). **`delivery.css` לא נוגעים בו — הוא ירושה נקייה.**

## מפת הקונסולה

שער ← אינדקס שיעורים ← עמוד-קונסולה פר-מפגש. כל עמוד-קונסולה = שלוש רצועות בדיוק כמו אתר-התלמיד (הכנה · בכיתה · בבית), וכל רצועה היא רצף **כרטיסי-צעד** ממוספרים. כל צעד = יחידה אחת ומציג שלושה דברים:

1. **מצגת** — כפתור "פתח מצגת" לדק של היחידה (או "דק בהכנה" כשהדק עוד לא הועתק).
2. **לינקים לפתיחה/שליחה** — עמוד-התלמיד של היחידה plus כלים/משאבים.
3. **הערת-מעבר** — מה אומרים בין היחידות (חוט-המעבר בלבד, לא run-sheet תפעולי).

## הרצה מקומית

הדפדפן חוסם טעינת קבצים מקומיים ב-`file://`. מתיקיית הריפו:

```
python -m http.server 8000
```

ואז http://localhost:8000 (או `npx serve`). ב-GitHub Pages הכל עובד מעצמו.

## מבנה הקבצים

- `index.html` · `sessions.html` · `session-<N>.html` — קליפת הניווט.
- `delivery.css` — שכבת העיצוב הירושה (לא נוגעים). `console.css` — הרכיבים המנחה-בלבד.
- `decks/session-<N>/<unit>/` — הדקים המתארחים (`slides.html` plus `assets/`).
- `README.md` · `HOW-TO.md` · `CLAUDE.md` — תיעוד וסוכן התחזוקה.

## מקור-אמת לסדר ולחלוקה
