# בניית Plugin — ראנשיט מנחה

> מסמך למנחה בלבד. כאן בדיוק מה אומרים ועושים בכל קטע. יחידה אחרונה של המפגש, סוגרת את הקשת: מכלים מוכנים לכלי משלנו שמתחבר לעולם.
> הנחת יסוד: התלמידים עברו בבית את ההכנה (Cowork, מה זה Plugin, ORBIT), והם עובדים ב-Cowork.
> הכנה שלך לפני השיעור, קריטית: הריצו מראש את פרומפט ה-showcase של Linear מחשבון רגיל ב-Cowork, וודאו שהוא באמת בונה plugin עובד שפותח פרויקט ב-Linear. בדקו גם את שני פרומפטי-המסלול (Linear ו-Canva). חברו מראש את Linear ו-Canva ב-Cowork. שימו לב לסייג החשבון החינמי של Claude: בחינם מותר חיבור מותאם אחד בלבד, וייתכן שכבר נוצל בהכנה; ב-Pro וב-Max אין מגבלה.

## 00:00–04:00 · גשר מ-3.4 ופתיחה

**המטרה:** הלומדים מבינים שהיום הם עוברים צד, מכלים מוכנים לכלי משלהם שמתחבר לעולם, ושנשארים בעולם של Tuesday.

**על המסך:** שקף פתיחה.

**מה אומרים (הגשר):**
"עד עכשיו השתמשנו בכלים שמישהו אחר ארז לנו. התקנו plugin מוכן, שיחקנו עם סקילים, ראינו את הפלאגין שמעביר מצגות. כל הזמן היינו בצד שמשתמש. היום אנחנו עוברים צד: אורזים את העבודה שלנו לכלי אחד משלנו, ומחברים אותו לעולם שבחוץ."

**מה אומרים (המסגרת):**
"זה הרגע שסוגר את כל המפגש. בהכנה התקנתם plugin מוכן וראיתם מבפנים שהוא בסך הכול אריזה של דברים שכבר הכרתם, סקיל, חיבור, פקודה וסוכן. עכשיו אתם בונים אחד כזה לבד, ב-Plugin Create, בלי שורת קוד אחת. הכול שיחה: אתם מתארים מה אתם רוצים, וה-Plugin Create בונה. נשארים בעולם של Tuesday, אותה חברה שליוותה אותנו בהכנה ובמצגות."

**לשים לב:** קצר. אל תיכנסו פה להגדרות, את החידוד עושים בסוף אחרי שבנו בידיים.

**מעבר:** "בואו נראה את זה בפעולה. אני בונה עכשיו plugin אחד מול העיניים שלכם." ← ההדגמה.

## 04:00–16:00 · הדגמה — showcase של Linear

**המטרה:** הלומדים רואים את כל מסלול הבנייה מקצה לקצה לפני שהם בונים לבד, ומבינים ש-plugin הוא אריזה של ארבעה רכיבים.

**על המסך:** Plugin Create, ואז החיבור ל-Linear.

**מה עושים:** מכיוון שהרצתם את זה מראש, אפשר להראות את התוצר האמיתי ולחזור על הרגעים החשובים. מדביקים את פרומפט-הפתיחה ל-Plugin Create:

```
אני רוצה לבנות plugin שהופך עבודה מבולגנת ללוח עבודה מסודר ב-Linear.

זה מה שהוא צריך לכלול:
- סקיל שיודע לקרוא ערימת משימות, תמלול פגישה או רשימת מטלות מפוזרת, ולפרק אותה למשימות ברורות. לכל משימה כותרת קצרה, אחראי משוער, עדיפות (גבוהה, בינונית או נמוכה), והערכת מאמץ קצרה.
- פקודה בשם plan/ שמפעילה את כל התהליך מההתחלה ועד יצירת הפרויקט.
- שימוש בחיבור Linear: לפתוח פרויקט חדש, ובתוכו ליצור את כל ה-issues עם הכותרות, האחראים והעדיפויות.
- סוכן בתפקיד מנהל פרויקט שמראיין אותי בקצרה לפני שהוא יוצר משהו: מה שם הפרויקט, מי בצוות, ומה הדדליין. רק אחרי שיש לו תשובות, הוא בונה את הלוח.

תעזור לי לבנות אותו צעד אחר צעד.
```

**מה אומרים (הבלגן שנכנס):**
"לקחתי ערימת משימות מבולגנת של Tuesday, פתק מהסנכרון השבועי. הכול מעורבב, באג דחוף לצד תורנות קפה, אחראים מרומזים בתוך המשפטים, בלי שום עדיפויות. הדבר שאף אחד לא אוהב לסדר ביד. ה-plugin הזה לוקח את הערימה ומחזיר אותה כפרויקט מסודר ב-Linear, כל פנייה הופכת ל-issue עם כותרת, אחראי ועדיפות."

**מה אומרים (שלושת הדגשים):**
- "זאת שיחה, לא קוד. ה-Plugin Create שואל שאלות, ואני עונה בשפה רגילה. אין תשובה נכונה, יש מה שאני רוצה שהכלי יעשה."
- "כש-Linear מתחבר, מאשרים גישה בדפדפן פעם אחת, וזהו, הדלת פתוחה."
- "שימו לב שהסוכן מראיין אותי לפני שהוא בונה. הוא לא קופץ ישר ליצירה, קודם שאלות קצרות, ואז לוח."

**מה אומרים (הקישור לרכיבים):**
"תראו במה ה-plugin הזה נגע, כי זה כל מה שהוא: סקיל שמפרק עבודה, פקודה אחת שמפעילה הכול, חיבור ל-Linear שפותח פרויקט אמיתי, וסוכן שמראיין. ארבעה רכיבים, אריזה אחת. לזה נחזור בסוף."

**לשים לב:** אם החיבור נופל בכיתה, אל תילחמו בו מול כולם. הראו את התוצר שהרצתם מראש והמשיכו, התלמידים יחברו לבד בקטע הבא.

**מעבר:** "עכשיו תורכם. כל אחד בונה plugin משלו, ובוחר מסלול." ← הבנייה.

## 16:00–36:00 · עכשיו אתם בונים — שני מסלולים

**המטרה:** כל לומד בונה plugin אחד משלו שמתחבר לעולם, במסלול Linear או Canva.

**על המסך:** המסכים של המשתתפים. אתם מסתובבים.

**מה אומרים (החיבור):**
"לפני שמתחילים, רגע על החיבור. ב-Cowork, אם הכלי כבר בספריית החיבורים, מוסיפים אותו בלחיצה. אם לא, בוחרים Add custom connector, מדביקים את הכתובת, ומאשרים בדפדפן. מי שעל חשבון חינמי של Claude, זכרו שמותר חיבור מותאם אחד בלבד, אולי כבר ניצלתם אותו בהכנה. ב-Pro וב-Max אין מגבלה."

**מה אומרים (מסלול Linear, הראשי):**
"המסלול הראשון הוא כמו ההדגמה, פקודה plan/ שמסדרת עבודה מבולגנת ללוח ב-Linear. החיבור הוא Linear בכתובת `https://mcp.linear.app/mcp`, התחברות דרך OAuth, עובד גם בחינם. הקלט הוא ערימת המשימות של Tuesday או שרשור הסלאק על מכונת הקפה, בחרו אחד כדי שלא כולם יפיקו לוח זהה. תדביקו ל-Plugin Create:"

```
אני רוצה לבנות plugin שמסדר לי עבודה ללוח ב-Linear.
אני נותן לו ערימת משימות מבולגנת או תמלול פגישה, והוא מפרק אותה למשימות, לכל אחת כותרת, אחראי משוער ועדיפות, ואז פותח פרויקט ב-Linear עם כל המשימות בפנים.
תהיה לו פקודה בשם plan/ שמפעילה את כל התהליך, וסוכן בתפקיד מנהל פרויקט שמראיין אותי בקצרה (שם הפרויקט, מי בצוות, מה הדדליין) לפני שהוא יוצר משהו.
תעזור לי לבנות אותו צעד אחר צעד.
```

**מה אומרים (מסלול Canva, הויזואלי):**
"המסלול השני לא מסדר, הוא מעצב. פקודה onepager/ שמפיקה ב-Canva עמוד מכירה אמיתי ומעוצב, מיוצא כקובץ PDF. שווה לחדד את ההבדל מ-brand-studio של ההכנה: שם ייצרנו תמונה מאפס, כאן עיצוב אמיתי וערוך שאפשר עוד לפתוח ולשנות, ובסוף מייצאים. החיבור הוא Canva בכתובת `https://mcp.canva.com/mcp`, OAuth, הליבה עובדת בחינם. הקלט הוא העובדות על Tuesday וערכת המותג. תדביקו ל-Plugin Create:"

```
אני רוצה לבנות plugin שמייצר עמוד מכירה מעוצב ב-Canva.
אני נותן לו את העובדות על המוצר ואת ערכת המותג, והוא בונה ב-Canva עיצוב אמיתי וערוך, בצבעים ובפונטים של המותג, ומייצא אותו כקובץ PDF מוכן לשליחה.
תהיה לו פקודה בשם onepager/ שמפעילה את זה, וסוכן שמראיין אותי בקצרה (מה המוצר, לאיזה קהל, ומה הפעולה שאני רוצה שהקורא יעשה) לפני שהוא מעצב.
תעזור לי לבנות אותו צעד אחר צעד.
```

**מה אומרים תוך כדי תנועה:**
- "מי שמנסה לכתוב קוד, להזכיר, ה-Plugin Create כותב, אתם רק מתארים מה אתם רוצים."
- "אם החיבור לא מתחבר, בדקו את סייג החשבון החינמי, או עברו למסלול שכבר חיברתם לו."
- "הסוכן אמור לראיין לפני שהוא בונה. אם הוא קפץ ישר, בקשו ממנו לשאול קודם."

**לשים לב:** שמרו על תנועה. מי שסיים מוקדם, יקבל בבית מאגר שלם להמשיך ממנו, אז שימשיך לבנות. מי שלא הספיק, ממשיך בבית מאיפה שעצר.

**מעבר:** "כולם בנו משהו? מצוין. רגע לפני שמסיימים, בואו נחדד ארבע מילים." ← החידוד.

## 36:00–41:00 · חידוד Plugin / Skill / Agent / Connector

**המטרה:** ארבע המילים מתקבעות, אחרי שכל אחת נגעו בה בידיים.

**על המסך:** שקף עם ארבע השורות.

**מה אומרים:**
"אחרי שבניתם בעצמכם, ארבע המילים האלה כבר לא מבלבלות:
- Plugin, אריזה. החבילה שעוטפת את כל השאר ומאחדת אותם לכלי אחד.
- Skill, יכולת. דבר אחד שהמערכת יודעת לעשות, למשל לפרק עבודה למשימות.
- Agent, פרסונה. דמות עם תפקיד והקשר, למשל מנהל הפרויקט שמראיין לפני שהוא בונה.
- Connector, דלת. חיבור לשירות חיצוני, למשל Linear או Canva.
ה-plugin שבניתם עטף כמה מאלה לתוך כלי אחד. זה כל הרעיון של אריזה."

**לשים לב:** אם מישהו מבלבל plugin עם skill, תחזרו לדוגמה שהוא בנה: "מה עטף את מה אצלך?"

**מעבר:** "וזה מה שלוקחים הביתה." ← הסגירה.

## 41:00–45:00 · סגירה ובית

**על המסך:** שקף סוגר.

**מה אומרים:**
"בניתם כלי משלכם, מקומי, מחובר לעולם, בלי שורת קוד. בבית מחכה מאגר של עשרים פרויקטים. תסיימו את מה שהתחלתם, ואז תבנו עוד אחד או שניים, הפעם לעולם האישי שלכם. יש שם גם טבלה שעוזרת לבחור כך שכמה בניות יחד יגעו בכל סוגי היכולות. את השיתוף של מה שבניתם, איך נותנים את הכלי לאחרים, נלמד בשיעור הבא. קודם בונים. אם יש שאלות, אני בוואטסאפ."

אין צורך בסבב שאלות פורמלי. סוגרים מיד אחרי המשפט הזה.
